# Spec: desktop-shell

Status: implemented (v0.2, native UI)

## 范围

mygo 桌面壳：窗口生命周期、菜单、native UI（package `ui`，纯 Go 自绘，无
webview、无 HTML/JS、无前端构建）与 `internal/service` 应用服务层。
壳不含任何 agent 逻辑。

## 产品规则

1. 界面用 mygo 的 package `ui` 写成：状态结构体 + `view(c *ui.Context)`
   方法，每帧由状态构建；无前端工具链（运行时与开发时都不需要 Bun/Node）。
2. UI 只通过 `internal/service` 的公开方法消费 agent 核心（见
   specs/agent-core.md 的事件序列）；事件在 `win.Update` 内应用到视图状态，
   agent 回合跑在独立 goroutine 上。
3. 设置（baseURL / apiKey / model）经设置弹窗（`ui.Modal`）读写，落盘到
   用户数据目录；API key 只存本地文件，不进日志、不进会话持久化、不在
   界面回显。
   剖面（issue #215）：settings 增 `profiles`（名 → {api, baseUrl,
   apiKey, model, thinking}）与 `active`；旧版单剖面设置首启自动迁移
   进 `default` 剖面（扁平字段语义不变——活动剖面物化进扁平字段，
   resolve/env 覆盖与 providerFor 路径零改动）。`/provider` 三形态：
   无参列剖面（当前带 → 标记）；`/provider <名>` 切换——下回合走新剖
   面，回执带名称/模型/端点；`/provider add <名>` 把当前配置注册为剖
   面。剖面 key 与扁平 key 同一条脱敏边界（SettingsView/日志/JSONL
   全链路不回显）；OAuth（订阅登录）与剖面正交，保持全局。
4. 会话侧栏支持：新建（系统目录选择对话框）、列出（含标题与运行状态）、
   切换、删除（菜单触发）。
5. 消息区：流式 assistant 文本用 `markdown.Stream`，完成后 `markdown.View`；
   列表跟随末尾（FollowEnd）；工具调用渲染为可折叠块（名称 · 参数摘要 ·
   状态点，展开见完整输出）。
6. 输入区：多行自动增高（`TextArea.Lines(1,8)`），Enter 发送 /
   Shift+Enter 换行；运行时按钮变为停止（触发 Abort）。
8. 附件（多模态输入）：📎 打开图片选择（png/jpg/gif/webp，多选），以
   chips 展示、发送前可移除；随下一条消息发送（文本必填）。单张上限
   5MB，超限或类型不符以 notice 提示。终端形态不支持附件。
   贴图（issue #216）：composer 的 Ctrl/Cmd+V 先探剪贴板位图（internal/
   clipimg：PNG 注册格式优先直取，CF_DIBV5/CF_DIB 解码后 PNG 化；非
   Windows 返回无图）；命中即走 📎 同一条附件通道（同一单张/总量上限
   与 notice），无图时按普通文本粘贴放行——不报错不吞文本。
7. 浏览器目标（wasm）：`go tool mygo build -platform web` 产出静态站点，
   `go run ./cmd/webfs` 注入内存文件系统垫片（wasm 的 syscall 层需要 Node
   形态的 fs 对象，wasm_exec.js 的回退只有 stdout）。浏览器上的语义：
   用户数据目录与工作区都在内存 FS（`main_wasm.go` 的 SetPath 与
   PickWorkspace 的 GOOS=js 分支），垫片把每个文件的改动（去抖合并）逐条
   写入本源 IndexedDB，并在 wasm 实例化前恢复——刷新不清空设置、会话与
   工作区文件（API key 随设置文件存于本源 IndexedDB，仅本地）；
   bash 工具明确报错拒绝（无进程模型）；权限确认弹窗照常阻塞运行；
   provider 经浏览器的 fetch 流式调用。

10. 终端面板（菜单「终端」/CmdOrCtrl+J）：聊天与输入区之间的底部抽屉，
   在当前会话的本地工作区跑用户 shell（mygo terminal 插件）。终端与工作
   区绑定，切换会话即重建；SSH 远程工作区明确提示暂不支持（Conn 选项留
   有后门）；库缺失或创建失败降级为错误提示，不崩；关闭面板与应用退出
   区绑定，切换会话即重建；SSH 远程工作区经 remote.Shell 打开交互远端 shell
   （PTY + WindowChange 尺寸传播；拨号失败退化为提示）；库缺失或创建失败降级为错误提示，不崩；关闭面板与应用退出
   都终止 PTY 子进程。
9. 文件树面板（菜单「文件树」/侧栏「文件」/CmdOrCtrl+B）：右列展示当前
   会话工作区的目录树（目录优先排序，懒展开，经服务过 path jail——本地与
   SSH 远程同源）；点文件打开只读预览弹窗（60KB 截断、二进制拒绝）；
   刷新清空缓存；切换会话清空树缓存。
12. MCP 诊断（设置弹窗「诊断 MCP」）：对全部配置的服务器并行探测——
   各自拉起新实例走完整 initialize 握手与 tools/list 后关闭，不动在跑
   集合；结果（✓ 工具清单（上限 12）/✕ 错误 + 延迟）就地展示，打开设置
   即清空上次结果；单服务器整体 15s 上限，探测在后台线程、结果回视图线程。
13. zgo doctor：CLI 环境诊断——provider 配置（key 只报有无，永不回显）、
   模型是否在目录（未知则提示窗口按默认估算）、MCP 服务器真探测（并行、
   复用设置面板同一诊断）、git/ssh 工具链可用性。退出码恒 0（诊断报告，
   非门禁）。
14. 跨会话搜索（菜单「搜索所有会话…」/CmdOrCtrl+Shift+F）：关键词后台
   流式扫全部会话的 JSONL（不整态装载；消息文本与工具参数参与，大小写
   不敏感），命中按会话列出（每会话至多 3、总上限 30，带上下文片段）；
   点命中切到该会话并把关键词沿用为会话内过滤；扫描带代次标记，关闭
   弹窗或新扫描使旧结果作废。扫描按重放态过滤（issue #141）：regenerate
   截断与 compaction 换摘要丢弃的消息不参与命中（只记序号不装消息体，
   维持流式）；compaction 摘要作为重放态的一部分照常可命中。
15. zgo sessions（CLI 运维面）：list 以表格列出标题/更新时间/工作区/token
   用量；export 按唯一 ID 前缀导出 HTML（默认）或 Markdown（--md，-o 指定
   输出；旗标须在 id 之前）；rm 按前缀删除。前缀歧义或未知 ID 以退出码 1
   报错，不误伤其它会话。
16. zgo memory（CLI 运维面）：list 按工作区列出记忆概况（最近写入/字
   节，无记忆标注）；show/add/clear 以 --workspace 指定（接受路径或会话 ID
   唯一前缀）；add 追加带时间戳条目；clear 幂等。
17. zgo models（CLI 运维面）：目录表（ID/协议/上下文/输出上限，--api 过滤，
   当前设置模型带 ← 标记）；--check <id> 离线校验（在目录或家族前缀命中 →
   ✓ 带参数，否则 ⚠ 按默认窗口估算）；目录内模型不告警。
18. /rewind [n]（终端三端）：无参回滚最近一轮、n 回滚到第 n 轮之前——
   与桌面 ⟲ 同语义（检查点 + 转录截断）；非 git 工作区降级为仅回退转录；
   坏参数给用法、越界给失败说明。
19. /export [md] [路径]（终端三端）：导出当前会话——默认自包含 HTML，
   md 走 Markdown；缺省文件名 zgo-export-时间戳；显式路径优先；失败给
   [导出失败] 说明。与桌面导出菜单、zgo sessions export 同一导出器。
20. zgo sessions search <关键词>（CLI 运维面）：跨会话检索——复用桌面搜索
   的同一 SearchSessions（文本+工具参数、片段、双上限）；表格式输出
   （会话前缀/标题/片段），无命中明确说明；与 export 前缀衔接。
21. 任务导航（ZCode task-navigation）：Ctrl+↑/↓ 在用户回合间跳转——跳离
   末尾停 FollowEnd，目标回合居中；边界不动；搜索过滤下沿匹配行跳转；
   切换会话重置定位。
22. 导出携带图片附件：用户消息中的图片块（📎 附件与 @ 引用成块的图）
   在 HTML 导出内嵌为 data URI 的 img、Markdown 导出为 data URI 图片
   链接——自包含分享物不依赖外部文件；非 image/* 媒体或空数据跳过
   （导出不因坏块失败）。
23. /resume [前缀]（终端三端）：无参切换到当前工作区最近会话，带唯
   一前缀切换指定会话（可跨工作区）；未知名/无历史会话给可读失败说
   明；切到当前会话明确提示不重复切换。切换后表面重置视图并回放目标
   会话转录（TUI 登记导航锚点），todo/任务注册表随会话隔离。
## 视觉基线（ui-refresh）

界面观感对齐 mygo 官方组件体系，约束如下（`internal/uiapp/kit.go` 是落点）：

1. **图标**：一律用内嵌 Lucide SVG（ISC 许可）经 `ui.Icon` 绘制，随文字
   色与字号缩放、随主题明暗变色；禁止以 emoji/Unicode 字形（▶ ✕ ✓ 📎 ✎
   等）充当图标。仅图标按钮必须有 `Label`（无障碍命名）与 `Tooltip`。
2. **状态呈现**：运行中用 `ui.Spinner`；成功/失败/停用分别以绿 ✓/红 ✕/
   灰 ■ 图标着色，不再拼进文本。
3. **工具调用卡片**：表面色卡片（Background+Border+Radius，MaxWidth 760），
   头部 `CollapsibleBase` 自绘（状态图标 + 等宽工具名 + 参数摘要），展开
   的输出区在卡内再沉一层底色块；diff 着色规则不变。
4. **提示浮层**（slash/mention）：`hintCard` 样式（表面色 + 边框 + 圆角 +
   轻阴影），读作浮层而非布局块；提示条目文本格式（`usage　—　help`、
   `@path`）不变——测试依赖。
5. **面板头部**：右侧抽屉（文件树/终端）统一 `panelHeader`（图标 + 标题 +
   右侧动作图标钮）。
6. **markdown 排版**：每帧把窗口主题接入 `markdown.Options`（链接=主题强
   调色、次要文字=TextMuted、行高 1.6）；不整份覆盖窗口主题——暗/亮与
   桌面强调色继续由系统决定。
7. **测试兼容**：视图测试只断言语义文本（按钮/条目文字、`计划 · n/m`），
   不依赖图标或字形记号。

## 状态所有者

| 状态     | 所有者           | 说明                              |
| -------- | ---------------- | --------------------------------- |
| 会话列表 | `service`        | UI 调 `ListSessions` 拉取镜像     |
| 视图状态 | `uiapp.App`      | 只在 view（主线程）与 win.Update 内改 |
| 流式文本 | Go 端事件源      | 视图状态是派生，不落库            |

## 验收场景

1. 冷启动：无会话时展示引导文案；无设置时提示先配置。
2. 流式渲染：text_delta 经 win.Update 上屏，列表吸底；工具块可折叠展开。
3. 中止：停止按钮触发 Abort，界面回到可输入状态。
4. 会话切换：历史经 `Messages` 恢复（含工具结果）。
5. 视图测试：`ui.NewTester` 无窗口运行 view，输入并提交后用户消息与
   agent_end 事件出现在视图状态中。
6. 浏览器目标：静态站点加载后窗口渲染；新建会话落在内存工作区；设置
   弹窗保存的配置经真实 provider 流式对话；写工具触发权限弹窗，未点击
   时运行阻塞；bash 工具返回明确的不可用错误。
7. 浏览器持久化：写文件 + 保存设置后刷新页面，会话列表与完整历史
   （含工具块）、设置（模型与 key）、工作区文件全部恢复；恢复后的会话
   可继续运行（读回文件并作答）。
8. 终端：打开面板即在当前工作区获得交互 shell；工厂失败显示「终端不可
   用」提示且重开重试；切会话换目录重建；关闭面板释放子进程。
7. 文件树：打开面板列出工作区（目录在前）；展开目录见子项；点文件出
   预览内容；切会话后树为新工作区的。
9. 终端（远程）：ssh 会话打开面板得到远端交互 shell；键入可达、输出回流、
   关闭即断。
10. MCP 诊断：坏命令的服务器报 ✕ 且给出可读错误；无配置时不出结果；
    诊断中按钮禁用、完成后展示。
11. doctor：全新安装报告「key 未配置/MCP 跳过/工具链可用」；配置了 key 与
    坏 MCP 的环境报告 provider 就绪与该服务器的 ✕ 行；任何输出不含密钥。
12. 跨会话搜索：多会话命中各自可点开并带过滤词；工具参数中的文件名可
    检索；无命中给出明确提示；关闭弹窗后旧扫描结果不再落地。
13. sessions CLI：list/export/rm 全链路（前缀解析、-o 显式输出、删除后
    列表反映）；未知与歧义 ID 明确报错。
14. memory CLI：list/show/add/clear 全链路（前缀解析工作区、追加可读回、
    清空幂等）；缺 workspace 拒绝。
15. models CLI：全目录与按协议过滤的表；未知当前模型告警、已知不告警且
    带 ← 当前；--check 对目录与家族变体 ✓、对未知 ⚠、空 ID 拒绝。
16. /rewind：默认与显式轮次两级回滚生效（转录反映）；坏参数与越界可读
    报错；/help 收录。
17. /export：默认 HTML、md 变体、显式路径三形态落盘且内容完整；
    /help 收录。
18. sessions search CLI：命中带标题与片段、无命中与空关键词各有明确行为、
    工具参数可检索。
19. 任务导航：三问三答的转录上，向上逐跳到第三/第二/第一问，边界不再
    动，向下可回；跳转停止跟随。
